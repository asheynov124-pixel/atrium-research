# atrium-research
Atrium — litigation-first legal research prototype. Public primary law, paragraph-pinned verification, calm editorial UI.

- [Session](index.html) — issue index and pinned quotes
- [Paragraph audit](audit.html) — paste a draft paragraph; recognized cites are pinned to a passage in this session, with flags for a wrong motion, overruled treatment, or a line the passage does not support
- [Verification slip](slip.html) — one authority, copied into the brief
